虚拟世界、
负熵与入口

文明是一个靠交换网络从外界获取负熵的耗散结构。当地球的物理边疆逼近上限，欲望就向两个方向外溢：太空，和虚拟世界。虚拟世界的上限由现实中的能源和算力决定。它的入口，就是下一代地租的争夺点。

来源与边界

只吸收经得起检验的部分。 #

来源是公众号「缠见如故」专辑《虚拟世界》，共 36 章（2024-08-16 至 2025-11-28）。本页是转述和框架对齐，不是原文。公众号全文有版权，公开仓库只放元数据、链接和转述。

可复用概念

先把能带走的概念分开，再决定哪些进入推导。 #

VW-C01 · 方法

论域决定视角

任何理论的意识形态秘密都藏在最初的定义里，定义者本身也被包含在定义中。

VW-C02 · 方法

分别到网络

分别形成分类，分类形成集合。集合分级、可流动，内外靠网络交换物质和能量。

VW-C04 · 硬

负熵获取能力

文明能力等于获取负熵的能力。一条线是人-物：科技、能源、交通。另一条是人-人：分工和组织。

VW-C11 · 硬

现实决定虚拟上限

虚拟世界的负熵来自现实能源。算力就是转化后的能源。虚拟世界没有独立的负熵来源。

VW-C10 · 硬

自相似与不可重复

虚拟世界复制现实结构，同时可复制、时间可逆、多样性高。复制几乎零成本，是技术特性，不是比喻。

VW-C12 · 可用

虚拟世界的实与虚

实是数据的产生、存储、传输、计算，加上能源。虚是虚拟人、资产、货币、社会与制度。

VW-C13 · 硬

虚拟世界之门

生物人进入虚拟世界的终端序列：电话、电视、电脑、手机、智能眼镜、脑机接口。

VW-C09 · 可用

两个世界的三特征

现实世界是物理性、资本化、社会性。虚拟世界是数据性、资本虚拟化、社会性。

VW-C05 · 假说

二元结构定律

现实在环境与结构的对抗中寻找最佳结构，也就是无限欲望与有限资源之间的妥协。

VW-C14 · 假说

三段走势

实中虚（数字化），虚中实（数据基建），虚中虚（数字社会）。虚拟人也有对应的三段，作者自己声明这是猜想。

VW-C08 · 类比

虚实相生

有实体就有对应的虚体。这是类比，不是证明，不能推出“虚拟人必然存在”。

VW-C16 · 不采纳

走势术语

进入段、中枢、离开段、区间套和“共振”是命理。不进入推导链。依赖它们的时间判断作废。

因果机制

虚拟世界不是另一套物理，而是现实负熵的一种去向。 #

M1

能源上限

现实能源决定算力，算力决定虚拟世界的规模与活性。虚拟世界没有独立的负熵来源。

能源账本对不上，数字文明叙事就打折。

M2

网络先于组织

交换网络升级，交通、信息和货币的交换成本下降，分工才能细化，更高级的组织才会出现。运河、铁路和互联网都是史料。

没有交换网络，就没有高级组织。

M3

欲望外溢

欲望无限，物理资源有限。无法满足的欲望先进入想象，神话和文学，再进入虚拟世界。

这是假说，要配可观察指标。

M4

双负熵线

科技（人-物）进步，社会组织（人-人）必须重组，二者互为反馈。只有一条线前进时会失衡。

与本库的剩余分配线同构。

M5

复制成本塌缩

数据复制的边际成本接近零，多样性爆炸。稀缺性和身份必须人为构造：账号、签名、许可、确权。

这些稀缺制造点是天然的 gate 候选。

M6

虚到实的反馈

数字孪生和仿真降低物理试错成本，物理建造可以因此加速。方向是硬的，原书里的具体百分比未核实，不能引用。

虚拟工具可以服务物理边疆。

M7

从属到独立

虚拟世界在达到现实同级之前从属于现实。一旦形成独立走势，就会与现实竞争话语权。

从属程度高时，虚拟主权只是修辞。

推导规则

拿来分析文明问题之前，先过这八条。 #

R1 · M1

先查能源账本。

判断任何数字文明、虚拟经济或 AI 叙事，先问电力、芯片、数据中心和冷却从哪里来，由谁定价。

R2 · M2

网络先于组织。

预测全球治理、虚拟国家或 DAO 能否出现，先看支撑它的交换网络是否已经存在，交换成本是否已经足够低。

R3 · M4

两条线都要查。

同时检查人-物（能源、技术成本曲线）和人-人（分工、制度、进入率）。只有一条线改善，标记为失衡风险。

R4 · M5

复制便宜，稀缺就会被制造。

零边际成本的领域里，价值集中到身份、确权、排序、分发和算力配额。这些点是 gate 候选。

R5 · M7

先确认从属关系。

虚拟系统的规则在多大程度上被云服务商、监管和芯片出口管制控制？从属程度高时，不要把虚拟主权当成事实。

R6

类比只能出假说。

虚实相生、社会形态自相似可以用来提出假说，不能用来得出结论。每个类比都要配一个可观察指标。

R7

规范和推论分开。

“大同”、人类命运共同体和“全球人口等于消费人口”是价值立场，不能当作推导出来的必然结论。

R8

不采纳走势命理。

K 线术语、5 倍规律和费根鲍姆类比不进入推导链。依赖它们的时间判断作废。

与建造者-攫取者框架

同构的留下，缺口补上，命理的丢掉。 #

剩余就是可自由调度的负熵。虚拟世界被明确列为一类边疆，有自己的实、虚两层。原书几乎不讲谁控制入口，这是本分支要补的缺口。

同构

剩余 = 负熵获取能力

本书把这条能力拆成人-物和人-人。本库的第一层因此多了一个分解，而不是多了一套语言。

扩展

新边疆包含虚拟世界

突破资源瓶颈有两条路：太空是物理边疆，虚拟世界是信息边疆。虚拟边疆有实、虚两层。

缺口

原书没有入口主体

它把方向交给笼统的“资本”。按本框架，方向取决于入口是协调型 gate，还是地租型 wall。

以本库为准

周期靠机制，不靠命理

“走势终完美”和生住坏灭在形式上像九步周期。本库的周期由剩余、入口和反馈推动。

张力

消费入口不是建造者入口

原书把全员消费人口化当终点。本库关心中位数人群能否获得建造者入口，而不只是消费入口。

边界不同

熵只作启发式

方向一致：开放系统要持续引入能量。本库明说熵是类比。原书把它当定律，还误称耗散结构驳倒了热寂说。采用本库边界。

强互补

虚拟边疆测试要加能源账本

新边疆测试在虚拟一侧必须加上：能源和算力成本是否下降，以及由谁控制。

一致

虚拟世界继承现实倾向

AI 会放大它所在系统的倾向。同一问题在不同模型里得到不同答案，说明开放还是封闭由现实决定，轶事本身不是证据。

同源

现实是第一前提

原书方法论说现实是一切逻辑前提的唯一基础，和思想星图的实事求是同源。命理和未核实数据违背了这一点。

补上缺失的攫取者

虚拟世界的六个入口。 #

检验方法沿用本库：移除或替换某个入口之后，虚拟世界的总剩余——创作者数量、新进入者、价格、质量——是上升还是下降。

01 · 门

终端和操作系统

手机、眼镜、脑机接口。谁决定能装什么，抽成多少？

02 · 身份

账号、实名、数字分身

身份是否可移植？能否被单方面注销？

03 · 算力和能源

配额、价格、出口管制

普通建造者能否买到算力和电力，还是只能租到别人定价的配额？

04 · 数据

采集权、确权、训练权

谁拥有数字孪生的原始数据？

05 · 价值

虚拟货币、支付、交易所

规则是否可审计？

06 · 规则

平台治理与模型对齐

内容审核和模型规则是否可复核、可挑战？本库的立场是：规则必须开放进入、可复核、可挑战。

原书第 36 章倾向于在全球层面掌握话语权、以大同为导向建立高级别规则。本库倾向开放入口、可审计、反黑箱。两者能达成的共识只有一点：虚拟世界的规则应当在它超越现实之前就确立。分歧在于由谁来定，以及规则是否可审计。

新的分叉

虚拟吸收式倒退，对照仿真加速建造。 #

欲望外溢给本库第十五层的高级倒退补上一种具体机制。判别指标：虚拟经济的增长，是在降低物理建造成本，还是在替代物理建设？

仿真加速建造

虚拟世界作为工具

数字孪生、仿真和 AI 设计降低物理试错成本，再推动能源、机器人和发射成本下降，通向星际边疆。

虚拟工具 → 试错成本下降 → 能源、机器人、发射成本下降 → 星际边疆

虚拟吸收式倒退

替代满足压低建造

物理边疆停滞之后，欲望在虚拟世界获得替代满足。资本流向注意力和虚拟资产地租，建造者乐观乘数下降，表面却很繁荣。

物理边疆停滞 → 虚拟替代满足 → 注意力与资产地租 → 建造者乐观乘数下降

明确拒绝

这些部分不进入本库的推导链。 #

命理

走势术语和 5 倍规律

进入段、中枢、离开段、区间套、“第六次大灭绝共振”的时间判断，以及费根鲍姆常数类比，都没有机制依据。

物理错误

耗散结构没有驳倒热寂说

耗散结构是局部有序，代价是向环境排熵。它不否定孤立系统的熵增。熵不能直接当成社会定律。

规范

大同不是逻辑必然

全球消费人口化、人类命运共同体，是价值立场和政治表述，不能以纯逻辑推导的名义使用。

未核实

没有来源的百分比不得引用

第 29、34 章的案例数字，以及“虚实相生所以虚拟人必然存在”，在核实之前只当作假说来源。细节见全书总结。

可证伪检验

每条假说都要写明什么观察会削弱它。 #

M1 能源上限

看用电和单位算力成本

若虚拟经济规模长期增长，同时能源和算力投入不增，且不能用效率提升解释，这条假说就被削弱。

M2 网络先于组织

看跨平台可移植率

若没有互通网络，却出现了稳定的跨平台虚拟组织，这条假说就被削弱。

社会形态自相似

看虚拟社区的实际路径

若游戏经济、加密社区和平台治理普遍跳过等级化阶段，或走出与现实无关的治理形态，自相似就不能当定律。

虚拟吸收式倒退

看虚拟消费对照硬科技

若虚拟消费上升，同时硬科技进入率和物理成本下降，说明两者互补，而不是替代。

入口地租

看抽成和独立开发者

若应用商店、云服务和模型 API 的抽成上升，但独立建造者的进入率和收入同步上升，这个入口更接近协调型 gate。
